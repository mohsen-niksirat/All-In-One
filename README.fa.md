# 🧩 آل‌این‌وان — مجموعه مینی‌اپ‌های تلگرام

> **English:** [Read the English version](README.md)

مجموعه‌ای از **مینی‌اپ‌های تلگرام، رایگان و سرورلس** — یک صفحه‌ی لانچر و کلی ابزار. همه‌ی اپ‌ها کاملاً در مرورگر اجرا می‌شوند: بدون بک‌اند، بدون دیتابیس، **با هزینه‌ی صفر** روی GitHub Pages.

## ✨ امکانات

- 🏠 **صفحه‌ی اصلی** — همه‌ی اپ‌ها در یک شبکه با جستجو و دسته‌بندی
- 🌍 **واقعاً چندزبانه** — فارسی / English، با یک لمس قابل تعویض (انتخاب شما ذخیره می‌شود)
- 🧱 **لایه‌ی مشترک** — `core/tg.js` (SDK تلگرام)، `core/store.js` (ذخیره‌سازی نام‌گذاری‌شده)، `core/i18n.js` (ترجمه)، `core/ui.css` (قالب)
- 📱 **حس تلگرامی واقعی** — تم روشن/تیره از تلگرام، بازخورد لمسی، دکمه‌ی بازگشت
- 💾 **داده‌ها روی دستگاه شما** — localStorage؛ هیچ‌چیز به سروری ارسال نمی‌شود (جز APIهایی که خودتان انتخاب کنید)

## 🚀 اپ‌های آماده

| اپ | کاربرد |
|----|--------|
| 🤖 **چت هوش مصنوعی** | گفتگوی استریمی با مدل‌های Groq (Llama 3.3، Gemma، Mixtral و…) — کلید API رایگان |
| 🍅 **تایمر پومودورو** | تایمر تمرکز با حالت کار/استراحت، حلقه‌ی پیشرفت و آمار جلسات |
| 📐 **تبدیل واحد** | طول، وزن، دما، داده، سرعت و زمان |
| 🔐 **تولید رمز عبور** | رمزهای قوی تصادفی با سنجه‌ی امنیت و تاریخچه |
| 🎲 **انتخاب تصادفی** | انتخاب برنده از لیست شما، با تاریخچه |

…و **۲۲ اپ دیگر در نقشه‌ی راه** (مدیریت کارها، عادت‌ساز، هزینه‌ها، آب‌وهوا، یادداشت‌ها، کد QR و…) — ببینید `apps/registry.js`.

## 🧱 ساختار پروژه

```
├── index.html           ← صفحه‌ی اصلی (لیست همه‌ی اپ‌ها)
├── launcher.css/.js
├── core/                ← لایه‌ی مشترک همه‌ی اپ‌ها
│   ├── tg.js            ← wrapper تلگرام (تم، لمسی، دکمه‌ی بازگشت)
│   ├── store.js         ← localStorage با فضای نام (tma:<app>:<key>)
│   ├── i18n.js          ← موتور چندزبانه (fa/en)
│   └── ui.css           ← متغیرهای تم + کامپوننت‌های مشترک
└── apps/
    ├── registry.js      ← متادیتای اپ‌ها (منبع واحد حقیقت)
    ├── ai-chat/         ← 🤖 (index.html + style.css + app.js + chat.js + groq-api.js)
    ├── pomodoro/        ← 🍅
    ├── unit-converter/  ← 📐
    ├── password-generator/ ← 🔐
    └── random-picker/   ← 🎲
```

## 🆕 چطور اپ جدید اضافه کنیم؟

۱. پوشه‌ی `apps/<your-app>/` را با `index.html` خودش بسازید (در صورت نیاز `style.css` و `app.js`).

۲. لایه‌ی مشترک را لود کنید:
   ```html
   <link rel="stylesheet" href="../../core/ui.css">
   <script src="../../core/tg.js"></script>
   <script src="../../core/store.js"></script>
   <script src="../../core/i18n.js"></script>
   ```
۳. ترجمه‌ها را ثبت و سپس مقداردهی کنید:
   ```js
   I18N.register('fa', { my_key: '…' });
   I18N.register('en', { my_key: '…' });
   TG.init({ backHref: '../../' });
   I18N.init();
   ```
۴. یک ورودی به `apps/registry.js` اضافه کنید (`status: 'ready'` و `path: 'apps/<your-app>/'`). تمام — در لانچر نمایش داده می‌شود.

> نکته: برای متن‌های ثابت از `data-i18n` / `data-i18n-placeholder` / `data-i18n-title` در HTML و برای متن‌های پویا از `I18N.t('key')` در JS استفاده کنید. برای تعویض زبان هم `<div data-lang-switcher class="lang-switcher"></div>` را به هدر اضافه کنید.

## 🌍 اضافه کردن زبان جدید

۱. به `dirs` در `core/i18n.js` زبان و جهت آن را اضافه کنید (مثلاً `ar: 'rtl'`).
۲. برای همه‌ی کلیدهای موجود دیکشنری جدید ثبت کنید — `I18N.register('ar', { … })`.
۳. نام زبان را به `nativeNames` در `core/i18n.js` اضافه کنید.
۴. نام و توضیح فارسی/انگلیسی را به ورودی‌های `apps/registry.js` اضافه کنید.

## 🚀 انتشار روی GitHub Pages

۱. این ریپو را روی گیت‌هاب پوش کنید.
۲. **Settings → Pages → Source: شاخه‌ی `main`** → Save.
۳. هاب شما روی `https://<username>.github.io/All-In-One/` فعال می‌شود.

### اتصال به بات تلگرام

۱. به [@BotFather](https://t.me/BotFather) پیام دهید → `/newbot` → توکن بگیرید.
۲. `/newapp` → بات را انتخاب کنید → **Web App URL** را آدرس Pages بدهید.
۳. بات را باز کنید → دکمه‌ی منو → هاب شما داخل تلگرام باز می‌شود (تم، لمسی و دکمه‌ی بازگشت خودکار کار می‌کنند).

### تنظیم چت هوش مصنوعی (اختیاری)

اپ چت AI به کلید رایگان Groq نیاز دارد: [console.groq.com/keys](https://console.groq.com/keys). داخل اپ → ⚙️ تنظیمات → کلید `gsk_…` را بچسبانید. کلید فقط روی دستگاه شما ذخیره می‌شود.
